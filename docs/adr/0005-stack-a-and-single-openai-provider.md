# 스택 A(TypeScript 단일 런타임)와 OpenAI 단일 공급자

1인이 웹·파이프라인·평가를 모두 만들고 풀스택 + 적용 AI 직무에 지원하는 포트폴리오다. 런타임은 TypeScript 하나로 통일한다: Next.js + React, PostgreSQL + pgvector, Drizzle, pg-boss, 웹과 워커를 분리한 pnpm 모노레포(패키지 다섯: 웹, 워커, 도메인, DB, 파이프라인). Python과 모델 학습은 두지 않는다. 모델 공급자는 OpenAI 하나만 쓴다.

## 고려한 대안

- **Python 워커 분리**: 두 런타임의 타입·배포·테스트를 따로 유지해야 한다. 학습이 없으므로 Python이 필요한 단계도 없다.
- **별도 벡터 DB**: 하루 300건 규모에서 pgvector로 충분하고, 운영·백업 대상이 하나로 남는다.
- **다중 모델 공급자**: 비용 추적, 프롬프트 버전 관리, 골든셋 평가가 공급자 수만큼 복잡해진다. 파이프라인은 모델 클라이언트를 주입받으므로 나중에 바꿀 수 있다.
- **Turborepo**: 패키지 다섯에는 pnpm 스크립트로 충분하다. 빌드 시간이 문제가 될 때 도입한다.

## 결과

- 도메인 패키지는 외부 의존성 0의 순수 TS이고, 웹과 워커는 도메인·DB·파이프라인을 import하되 서로는 import하지 않는다.
- 골든셋 교차 검증도 같은 공급자의 두 모델로 한다([ADR-0006](0006-golden-set-two-model-cross-check.md)).
- 배포 대상, 스케줄러, 관측 도구, 단계별 모델 배정은 리서치 #6·#7 뒤 스펙에 채운다. 이 ADR은 런타임과 공급자 선택만 다룬다.
