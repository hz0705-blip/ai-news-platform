# Triage 라벨

스킬들은 다섯 가지 표준 triage 역할로 말한다. 이 파일은 그 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 대응시킨다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 의미 |
| ------------------------ | ------------------ | -------------------------------------- |
| `needs-triage`           | `needs-triage`     | 메인테이너가 이 이슈를 평가해야 함     |
| `needs-info`             | `needs-info`       | 보고자의 추가 정보를 기다리는 중       |
| `ready-for-agent`        | `ready-for-agent`  | 완전히 명세됨, AFK 에이전트가 착수 가능 |
| `ready-for-human`        | `ready-for-human`  | 사람이 구현해야 함                     |
| `wontfix`                | `wontfix`          | 처리하지 않음                          |

스킬이 역할을 언급하면(예: "AFK 준비 triage 라벨을 붙여라") 이 표의 대응 라벨 문자열을 쓴다.

실제로 쓰는 용어에 맞추려면 오른쪽 열을 수정한다.
