# Research: user journey, user flows, UI/UX patterns

**Deliverable path:** `docs/research/02-ux.md`

## Questions to answer

1. **Persona hypotheses.** 3 personas, each tagged Korean-market / global / both. Ground them in evidence (surveys, Reuters Digital News Report, Korea Press Foundation reports, etc.).
2. **User journey** from discovery → onboarding → daily reading → deep dive on a story → follow/alerts → share/return. Where do news apps lose users? Cite.
3. **Five core user flows** as text diagrams (Mermaid or ASCII): first-run onboarding, daily briefing, story deep-dive (cluster → sources → timeline), follow a topic/entity, search.
4. **UI patterns specific to AI news analysis**: story clusters, timelines, source spectrum / bias indicators, summary confidence & uncertainty display, citation highlighting, "why am I seeing this". Link to screenshots or product pages of concrete examples. Note what regulators/researchers say about displaying bias labels responsibly.
5. **Design system choices** for a solo dev in 2026: shadcn/ui, Radix, Tailwind v4, Base UI, others. Dark mode, WCAG 2.2 requirements, long-form reading typography, mobile-first vs desktop-first for news consumption (cite usage data), Korean typography specifics (fonts, line-height, word-break).
## Project context

An **AI-powered general-news analysis web app**: it ingests general news (politics, economy, tech, …), then summarises, clusters and analyses it for readers. Solo developer. Purpose: a **product-grade portfolio** targeting both **full-stack** and **AI/ML engineer** roles. Target market (Korean vs global) is **undecided** — research **both** and keep them separate where they differ.
