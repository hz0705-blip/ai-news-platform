# wrap-up — 세션 인계 문서

다음 세션은 빈 컨텍스트로 시작해 이 문서만 보고 이어간다. 대화에서만 알 수 있는 것을 남기고, 스펙·계획·ADR·이슈·커밋에 이미 있는 내용은 경로로만 가리킨다. 비밀 정보는 넣지 않는다. 보고 형식(명령문 아님), 한국어.

## 쓰기

메인 체크아웃의 `.scratch/handoff.md`에 아래 여섯 절을 이 순서로 쓴다(워크트리 안이어도 메인 체크아웃 경로). `.scratch/`가 없으면 만든다.

1. **상태**: `scripts/handoff-state`를 한 번 실행해 출력(브랜치·SHA·작업 트리·워크트리·열린 PR·OPEN 이슈의 라벨·담당자)을 그대로 붙이고, 세션이 바꾼 시크릿·환경·워크플로 사실을 덧붙인다.
2. **이번 세션에서 한 것**: 결과 위주, 파일 경로와 커밋 SHA.
3. **다음 할 일**: 순서대로. 첫 항목은 다음 세션이 그대로 실행할 수 있게 구체적으로(명령 또는 파일 경로).
4. **경위·판단 이유**: 사용자가 택한 선택지와 이유, 기각한 대안, 미해결 질문, 서브에이전트 답변 중 재확인이 필요한 것.
5. **참조 경로**: 계획 파일(`~/.claude/plans/…`), 메모리 파일, 임시 파일과 그 수명(재부팅 시 소멸 여부).
6. **제안 스킬**: 다음 세션이 첫 행동에 부를 스킬 이름.

## 마무리

1. 오래 남길 사실이 있으면 메모리(`~/.claude/projects/…/memory/`) 또는 ADR·`docs/agents/project.md`로 옮긴다. 인계 문서는 1회용이다.
2. `.scratch/.task-done`을 삭제한다.
3. 사용자에게 "세션을 종료해도 됩니다"와 인계 문서 경로를 알린다.
